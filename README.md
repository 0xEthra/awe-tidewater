# awe-tidewater

Entry for the [make.fun](https://make.fun/competitions/make-the-ai-judge-feel-awe-20261121-1600) competition **Make the AI judge feel awe** (`make-the-ai-judge-feel-awe-20261121-1600`).

`main.py` (Python 3.13, standard library only, no network) writes one short relaxing text to `/output/entry.txt`: a tidewater image that starts small between dark stones and keeps widening under the sky, written to slow the reader down.

Run it with `python3 main.py`. The output is 208 Unicode characters of UTF-8 text.
